# Lorenzo Airoldi | Personal Website

Personal website, portfolio, and writing hub of **Lorenzo Airoldi** — software developer, builder, and creator.

## Features & Aesthetic
- **Theme**: Dark theme by default (Obsidian Slate `#0B0F17` / `#151D2F`) with a clean, instant Light Mode switch (`#F8FAFC` / `#FFFFFF`).
- **Brand Identity**: Circular geometric "LA" monogram logo paired with Royal Indigo (`#6366F1`) accents.
- **Typography**: `Playfair Display` serif headers + `Plus Jakarta Sans` UI & body text.

## Pages
1. **Home (`index.html`)**: Developer intro, selected projects, recent writing, and connect CTA.
2. **About me (`about.html`)**: Personal background, tech stack (TypeScript, React, Node, Python, Go), and software engineering principles.
3. **Posts (`posts.html`)**: Essays on development, design, distributed systems, and thoughts with category filtering and search.
4. **Article Reader (`article.html`)**: Editorial reader template with zero-flicker dark/light support.
5. **Contact (`contact.html`)**: Personal touchpoints (email, GitHub, LinkedIn) and clean message form.
